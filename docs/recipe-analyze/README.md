# Recipe analyze artifacts

Generated by `make recipe-analyze` (or `make recipe-audit`).

| File | Contents |
|------|----------|
| `summary.md` | Per-mod counts + AgriCraft plant namespace table |
| `by-mod/<mod>.txt` | Item ids whose recipes appear in `docs/recipe_data.json` |
| `*-seeds.txt` | Seed-like result ids for farming namespaces |
| `agricraft-plants.txt` | AgriCraft datapack plants (products / genetics) |

**Refresh after mod list / KubeJS changes:** `make recipe-audit`, then commit
`docs/recipe_data.json` and this directory. Do not copy Verdant dumps.

`scripts/analyze_recipe_wiki.py` is assembled from `.github/recipe-analyze-parts/`
on first `make recipe-analyze` if missing (same pattern as recipe_wiki_core).

Nested AgriCraft datapacks (e.g. `mysticalagriculture`, `pamhc2crops`) only apply
in-game when those mods are installed; the plant list still records what the JAR
ships so lane work can see the full catalog.
