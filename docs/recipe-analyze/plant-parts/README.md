# AgriCraft plant list parts

Concatenated to `../agricraft-plants.txt` by `make recipe-analyze` when that file
is missing (or by: `cat plants.part* > ../agricraft-plants.txt`).

Regenerated as a whole from Prism mod JARs when `make recipe-analyze` can scan
AgriCraft. Nested datapacks (MA, Pam's, etc.) only apply in-game if those mods
are installed.
